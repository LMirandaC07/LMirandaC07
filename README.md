## 💻 Sobre mim

Sou **Luis Gustavo**, estudante de **Análise e Desenvolvimento de Sistemas na Universidade Católica de Brasília (UCB)** e desenvolvedor em formação com interesse em **Back-end e Front-end**.

No Back-end, venho trabalhando principalmente com **Java e Spring Boot**, criando APIs REST, regras de negócio, autenticação, persistência e testes. No Front-end, desenvolvo interfaces com **React e Angular**, além de JavaScript, HTML, CSS e Tailwind CSS.

Gosto de transformar o que estudo em projetos completos. Por isso, procuro praticar não apenas CRUD, mas também problemas como **concorrência, autenticação, integração entre front e back, Docker, migrations, testes e integração com IA**.

> 🎯 Atualmente busco minha primeira oportunidade de **estágio em desenvolvimento de software**, onde eu possa contribuir com projetos reais e continuar evoluindo com um time de desenvolvimento.

### 🐾 VetVoice AI

**API de gestão para clínica veterinária.**

Além do gerenciamento de clientes, pets, veterinários e consultas, explorei um problema real de sistemas de agenda: **duas requisições tentando reservar o mesmo horário**.

**Destaques**
- API REST com Spring Boot
- PostgreSQL + Flyway
- Docker Compose
- validação e tratamento de erros
- proteção contra double-booking
- teste com **10 requisições concorrentes**
- integração experimental com Spring AI

**Stack**  
`Java 21` `Spring Boot` `PostgreSQL` `Docker` `JUnit`

**Aplicação Full Stack para controle financeiro pessoal.**

Projeto criado para integrar uma API Java com uma aplicação web, incluindo autenticação e persistência dos dados financeiros do usuário.
